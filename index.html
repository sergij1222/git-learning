Що таке GNU/Linux?

GNU/Linux — це операційна система з відкритим програмним кодом, яка використовується на комп'ютерах, серверах та інших пристроях.

Основою системи є ядро Linux, а різні програми та компоненти GNU допомагають користувачу працювати з операційною системою.

Відкритий код

Код Linux доступний для перегляду та зміни. Це дозволяє розробникам створювати власні рішення та покращувати систему.

Велика кількість систем

На основі Linux створено багато різних дистрибутивів, які призначені для різних завдань і користувачів.

Популярні дистрибутиви Linux

Дистрибутив — це готова операційна система на основі ядра Linux, яка містить необхідні програми та інструменти.

U

Ubuntu

Один із найпопулярніших дистрибутивів Linux. Підходить для навчання, роботи та повсякденного використання.

D

Debian

Відомий стабільністю та великою кількістю доступних програмних пакетів.

F

Fedora

Сучасний дистрибутив, який часто використовують для розробки програмного забезпечення.

A

Arch Linux

Гнучкий дистрибутив, який дозволяє користувачу самостійно налаштовувати систему.

M

Linux Mint

Зручний дистрибутив для користувачів, які переходять з інших операційних систем.

K

Kali Linux

Дистрибутив, орієнтований на тестування безпеки та завдання кібербезпеки.
