Що таке система контролю версій?

Система контролю версій — це програмне забезпечення, яке дозволяє відстежувати зміни у файлах проєкту, зберігати різні версії та повертатися до попередніх станів проєкту.

Системи контролю версій особливо важливі під час розробки програмного забезпечення, оскільки над одним проєктом часто працює декілька людей.

Що таке Git?

Git — це розподілена система контролю версій, яка використовується для відстеження змін у файлах та керування програмними проєктами.

Git був створений Лінусом Торвальдсом у 2005 році. Сьогодні Git є одним із найпоширеніших інструментів для роботи з програмним кодом.

Основні можливості та переваги Git

Історія змін

Git зберігає інформацію про зміни файлів, тому можна переглядати історію роботи над проєктом.

Гілки

Branch дозволяє створювати окремі гілки для розробки нових функцій.

Командна робота

Кілька розробників можуть працювати над одним проєктом та об'єднувати свої зміни.

Резервне зберігання

Репозиторій можна зберігати на GitHub, що допомагає не втратити код.

Відновлення

За необхідності можна повернутися до попередньої версії проєкту.

Безкоштовність

Git є безкоштовним програмним забезпеченням з відкритим кодом.

10 базових команд Git

1. git init

git init

Створює новий локальний Git-репозиторій у поточній папці.

2. git clone

git clone URL

Копіює існуючий віддалений репозиторій на комп'ютер.

3. git status

git status

Показує поточний стан файлів та репозиторію.

4. git add

git add .

Додає зміни до індексу перед створенням коміту.

5. git commit

git commit -m "Опис змін"

Зберігає підготовлені зміни в історії Git.

6. git log

git log

Показує історію комітів репозиторію.

7. git branch

git branch

Показує існуючі гілки або використовується для створення нових гілок.

8. git switch

git switch назва-гілки

Перемикає користувача на іншу гілку.

9. git pull

git pull

Завантажує зміни з віддаленого репозиторію та об'єднує їх з локальною версією.

10. git push

git push

Відправляє локальні коміти до віддаленого репозиторію.
