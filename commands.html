LINUX TERMINAL

10 базових команд Linux

Командний рядок Linux дозволяє керувати файлами, папками та системою за допомогою текстових команд. Нижче наведені основні команди та приклади їх використання.

serhii@linux — bash
Welcome to the Linux terminal!
Введіть help, щоб переглянути доступні команди.
Спробуйте: pwd, ls, cd, mkdir, touch, echo Hello
serhii@linux:~$
Підказка: введи help, щоб побачити всі доступні команди. Для виконання команди натисни Enter.
01

pwd

Показує повний шлях до поточної папки.

serhii@linux:~$ pwd

/home/serhii

02

echo

Виводить текст або значення змінної на екран.

serhii@linux:~$ echo "Hello Linux"

Hello Linux

03

ls

Показує файли та папки у поточному каталозі.

serhii@linux:~$ ls

Documents   Downloads   Music

Pictures   Videos   file.txt

04

cd

Використовується для переходу в іншу папку.

serhii@linux:~$ cd Documents

serhii@linux:~/Documents$

05

touch

Створює новий порожній файл.

serhii@linux:~$ touch file.txt

serhii@linux:~$

06

mkdir

Створює нову папку.

serhii@linux:~$ mkdir test

serhii@linux:~$

07

cp

Копіює файл або папку.

serhii@linux:~$ cp file.txt copy.txt

serhii@linux:~$

08

mv

Переміщує або перейменовує файл чи папку.

serhii@linux:~$ mv file.txt Documents/

serhii@linux:~$

09

rm

Видаляє файл.

serhii@linux:~$ rm file.txt

serhii@linux:~$

10

history

Показує список команд, які виконувалися раніше.

serhii@linux:~$ history

1   pwd

2   ls

3   cd Documents
