# Git — система контролю версій

## Про проєкт

Цей репозиторій містить навчальну веб-сторінку,
присвячену системі контролю версій Git.

## Що таке Git?

Git — це розподілена система контролю версій,
яка використовується для відстеження змін у файлах
та керування програмними проєктами.

## Основні переваги

- збереження історії змін;
- можливість працювати з гілками;
- командна робота;
- можливість повернення до попередніх версій;
- інтеграція з GitHub;
- безкоштовне використання.

## Основні команди

| Команда | Призначення |
|---|---|
| `git init` | Створення репозиторію |
| `git clone` | Клонування репозиторію |
| `git status` | Перевірка стану |
| `git add` | Додавання змін |
| `git commit` | Створення коміту |
| `git log` | Перегляд історії |
| `git branch` | Робота з гілками |
| `git switch` | Перемикання гілки |
| `git pull` | Отримання змін |
| `git push` | Відправлення змін |
